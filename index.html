Algoritma, Programming & Kenapa Python?

Algoritma adalah urutan langkah logis untuk menyelesaikan masalah — persis kaya resep mie instan: rebus air, masukin mie, tunggu 3 menit, sajikan. Programming adalah cara menuliskan algoritma itu dalam bahasa yang dimengerti komputer.

Kenapa Python? Karena syntax-nya mirip Bahasa Inggris, dipakai luas di industri (AI, data, web), dan paling ramah untuk pemula.

IDE (Integrated Development Environment) itu simpel: tempat kamu nulis kode dan langsung lihat hasilnya. Sepanjang halaman ini, tombol Run di tiap kotak kode mensimulasikan itu.

Loops

Kode yang berulang otomatis. Atur angkanya, lihat berapa kali dan apa yang tercetak.

Coba

while Loop

while_loop.py
i = 1
while i <= 5:
    print(i)

Coba

for Loop

for_loop.py
for i in range(0, 10, 2):
    print(i)

range(start, stop, step) menghasilkan angka dari start sampai sebelum stop, meloncat sebesar step.

Coba

break & continue

break_continue.py
for i in range(1, 10):
    if i == 5:
        break
    print(i)

break langsung menghentikan loop. continue melewati sisa kode di iterasi itu dan lanjut ke angka berikutnya.

Coba

Nested Loop — Pola Bintang
